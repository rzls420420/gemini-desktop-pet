# 哈基米小姐（Gemini 猫娘）桌宠：Linux

本包包含完整 10 组透明版加倍动作素材（130 帧 RGBA PNG），不包含原始生成图或账号凭证。

需要 Python 3.10+、PyQt5，以及可用的图形桌面（X11/Wayland 兼容会话）。Ubuntu 可通过系统包管理器安装 `python3-pyqt5`。

- 解压后运行 `./start.sh` 即可独立启动桌面宠物。
- 运行 `./follow-antigravity.sh` 可启动后台监视器：检测到 Antigravity 主进程启动时自动拉起桌宠，Antigravity 退出时自动关闭；若已勾选「开机启动」，桌面登录时直接启动，不再随 Antigravity 退出而关闭。

## 交互与功能
- **左键点击/拖动**：唤醒或互动、自由拖动窗口位置。
- **右键菜单**：`立即睡觉`、`叫醒`、`查询额度`、`查看上下文状态`、`查看 Antigravity 状态`、`开机启动`、`预览动作`（9 组日常/工作动作）、`退出`。
- **任务与状态联动**：自动监听 `~/.gemini/antigravity/brain/` 会话记录；安装并启用 `antigravity-pulse` 面板插件时，会与对话栏底部同步显示上下文窗口占用（如 `241.6K / 512K (47%)`）及缓存命中率（如 `84.3%`），并汇总近 5 小时 / 今日真实 Token 消耗；如安装了 `account-switcher` 插件，会附带读取其非凭证配额快照及重置状态。
